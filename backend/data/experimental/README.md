# Experimental data overlay

`context.json` is generated by:

```bash
python3 data/experimental/build_experimental_data.py
```

Add `--with-nces` to download the large national NCES membership file and
match public-school enrollment by normalized school name. Without it, school
capacity is used only where OpenStreetMap publishes a capacity-like tag.

It contains public ACS, LODES, and OpenStreetMap-derived attributes used by the
ripple experiment. The generator never connects to or writes to PostgreSQL.
The generated JSON and downloaded extracts are intentionally gitignored.
